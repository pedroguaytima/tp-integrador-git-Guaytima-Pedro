# Landing page: Elecciones Independiente 2026

## Descripción

Landing page muy simple, hecha con HTML y CSS, que informa sobre las elecciones del Club Atlético Independiente: fecha de la votación, cantidad de socios en el padrón y los candidatos con sus agrupaciones y propuestas principales.

## Objetivo

Aplicar el flujo básico de trabajo con Git y GitHub (commits, ramas, issues y pull requests) sobre un proyecto digital pequeño y claro.

## Estructura del repositorio

- `README.md`: explica el proyecto.
- `ENTREGA.md`: registro del proceso de trabajo y enlaces de la entrega.
- `proyecto/index.html`: página principal con el contenido.
- `proyecto/style.css`: estilos de la página.
- `proyecto/escudo.svg`: imagen empleada para la resolución de la issue.
